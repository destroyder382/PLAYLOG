# PLAYLOG 🎮

**PLAYLOG** — небольшая консольная программа на Python для управления личной библиотекой видеоигр.

## Возможности

- Добавление игр в библиотеку
- Просмотр списка игр с нумерацией
- Удаление игр с подтверждением
- Сохранение библиотеки между запусками программы
- Обработка некорректного пользовательского ввода

## Технологии

- Python
- JSON для хранения данных

## Запуск

1. Установите Python 3.
2. Скачайте или клонируйте репозиторий.
3. Запустите программу командой:

   ```bash
   python main.py
   ```

## О проекте

PLAYLOG — учебный проект, созданный для практики Python, работы с функциями, списками, файлами и обработкой ошибок.
